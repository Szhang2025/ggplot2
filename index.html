An introduction to ggplot2

Build graphics one layer at a time, using every scheduled flight that left New York City in 2013 (nycflights13).

The grammar of graphics

ggplot2 treats a plot as a sentence assembled from a few parts. You start with data, say which columns map to which visual properties, then choose shapes to draw.

dataA data frame, one row per observation.
aes()Aesthetic mappings: columns to x, y, colour, fill, size.
geom_*()The shapes: points, bars, lines, boxes.
facet_*()Small multiples, split by a variable.
theme_*()Fonts, grid lines, background.

Layers are joined with +. Every plot below follows the same pattern:

ggplot(data = <DATA>, mapping = aes(<MAPPINGS>)) +
  <GEOM_FUNCTION>() +
  <OTHER_LAYERS>()

Setup

# install.packages(c("tidyverse", "nycflights13"))
library(tidyverse)      # loads ggplot2, dplyr, and friends
library(nycflights13)   # flights, airlines, airports, planes, weather

glimpse(flights)        # 336,776 rows, 19 columns

flights records departure and arrival times, delays in minutes, the carrier, origin and destination airports, and distance. Delays are negative when a flight is early.

Look at the data first

Search across every column, filter by origin, or click a column name to sort. The table holds a random sample of 1,500 of the 336,776 flights so this page stays light. The plots use all rows.

In R, the equivalent of the search box is filter():

flights |>
  filter(origin == "JFK", dest == "LAX", dep_delay > 60)

Scatterplot: geom_point()

Two numeric columns call for points. Do late departures lead to late arrivals?

ggplot(flights, aes(x = dep_delay, y = arr_delay)) +
  geom_point(alpha = 0.2) +
  labs(x = "dep_delay (min)", y = "arr_delay (min)",
       title = "Late departures mean late arrivals")

Bar chart: geom_bar()

With only x mapped, geom_bar() counts rows for you. Mapping fill to a column colours each bar.

ggplot(flights, aes(x = origin, fill = origin)) +
  geom_bar(show.legend = FALSE) +
  labs(title = "Flights by origin airport, 2013")

Histogram: geom_histogram()

A histogram bins one numeric column. Here we zoom in on delays between -20 and 120 minutes.

flights |>
  filter(dep_delay > -20, dep_delay < 120) |>
  ggplot(aes(x = dep_delay)) +
  geom_histogram(bins = 40, fill = "steelblue", colour = "white")

Boxplot: geom_boxplot()

To compare a numeric column across groups, put the category on x. reorder() sorts carriers by their median delay.

ggplot(flights, aes(x = reorder(carrier, arr_delay, median, na.rm = TRUE),
                    y = arr_delay)) +
  geom_boxplot(fill = "lightblue", outlier.shape = NA) +
  coord_cartesian(ylim = c(-40, 80)) +
  labs(x = "carrier", y = "arr_delay (min)")

Lines: geom_line() and summaries

Summarise with dplyr first, then map colour to a column to get one line per group and a legend for free.

flights |>
  group_by(month, origin) |>
  summarise(mean_delay = mean(dep_delay, na.rm = TRUE), .groups = "drop") |>
  ggplot(aes(x = month, y = mean_delay, colour = origin)) +
  geom_line(linewidth = 1) +
  geom_point() +
  scale_x_continuous(breaks = 1:12)

Facets: facet_wrap()

Instead of colouring by group, split the plot into panels that share the same scales.

ggplot(flights, aes(x = distance, y = air_time, colour = origin)) +
  geom_point(alpha = 0.4, show.legend = FALSE) +
  facet_wrap(~ origin)

Themes and saving

Themes change the non-data look. Try theme_minimal(), theme_bw() or theme_classic(), and save with ggsave().

p <- ggplot(flights, aes(x = origin, fill = origin)) + geom_bar()

p + theme_minimal(base_size = 14)
ggsave("flights-by-origin.png", p, width = 7, height = 4, dpi = 300)
Data: nycflights13 (Hadley Wickham), 336,776 flights from EWR, JFK and LGA in 2013. The plot images here were drawn with Python's matplotlib in ggplot style from the full data set, so run the R code above to get the native ggplot2 versions.
